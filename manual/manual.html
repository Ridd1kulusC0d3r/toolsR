⛏️ GARIMPO · manual ilustrado · família DEIVOSINT

Versão 2.0.0 · motor de pivô OSINT passivo · 100% Python padrão · sem chaves de API · 28 fontes · painel web · servidor MCP · STIX 2.1 · monitoramento · cadeia de custódia forense · dossiê em português

1 · O que é o GARIMPO (para quem nunca viu)

Você entrega um ponto de partida — um site, um e-mail, um CNPJ, um usuário do GitHub, um IP — e o GARIMPO:

  1. Descobre sozinho o tipo do que você digitou;
  2. Consulta só fontes públicas e passivas (ele nunca "bate na porta" do alvo);
  3. Segue as pistas: cada descoberta confiável vira um novo ponto a investigar, dentro de limites rígidos;
  4. Guarda cada resposta bruta com lacre digital (hash SHA-256 encadeado) — se alguém alterar um byte depois, o lacre denuncia;
  5. Entrega um dossiê em HTML, em português, que abre em qualquer navegador, sem internet.

Novo na 2.0:

  • Painel no navegador — investigue, explore o grafo arrastando os nós e abra cada evidência, sem terminal; NOVO
  • Monitoramento — repita a coleta e veja o que mudou no alvo (subdomínio novo, porta nova, sócio que entrou); NOVO
  • Exportações — STIX 2.1 (para MISP/OpenCTI), GraphML (Gephi) e CSV (Maltego/planilha); NOVO
  • Servidor MCP — o Claude (e outros assistentes) passam a usar o GARIMPO como ferramenta; NOVO
  • 28 fontes, incluindo o pulo do gato brasileiro: domínio .br → CNPJ do titular (RDAP do registro.br) → sócios → endereço. NOVO

Tudo isso sem instalar nada além do Python que provavelmente já está no seu computador, e sem nenhuma chave de API.

⚖️ Uso legal e autorizado apenas. "Passivo" significa que o alvo não recebe requisições suas — mas cada serviço público consultado (Google DNS, crt.sh, Shodan, BrasilAPI…) vê o que você pesquisou. Passivo não é anônimo.

5 · Painel web (sem terminal) NOVO

Ação única: dois cliques em GARIMPO-Painel-… (ou python3 garimpo.py painel). O navegador abre em http://127.0.0.1:8765. Primeira vez? Clique em Abrir a demonstração.

1 2 3 4 5 6 7 8 9
1Digite o alvo. Embaixo aparece o tipo detectado — confira antes de garimpar.
2Garimpar: a investigação roda em segundo plano, com barra de progresso das requisições.
3Comparar com coleta anterior: escolha um caso antigo do mesmo alvo e o novo já vem com o quadro de mudanças.
4Seus casos, do mais novo para o mais antigo. Clique para reabrir.
5Métricas do caso: consultadas, fronteira, vínculos, requisições gastas do orçamento.
6Ações: verificar a custódia, abrir o dossiê e exportar (STIX 2.1, GraphML, CSV, JSON).
7Mudanças desde a coleta anterior: verde surgiu, vermelho sumiu.
8Grafo interativo: arraste os nós; clique para ver os fatos. Pontilhado = fronteira; tracejado = vínculo fraco.
9Cada fato com a fonte e a evidência (#n): clique para ver a resposta bruta; passe o mouse para ver SHA-256, status e URL.
🔒 O painel só aceita conexões do próprio computador (127.0.0.1) e recusa pedidos de outros sites (proteção contra CSRF e DNS rebinding). Para encerrar, feche a janela do terminal/lançador.

13 · Glossário

OSINT
Inteligência de fontes abertas: informação pública, coletada legalmente.
Passivo
Coleta que não envia requisições à infraestrutura do alvo — só a terceiros que já têm dados sobre ele.
Seed
O ponto de partida da investigação (o valor que você digitou).
Pivô
Usar uma descoberta como novo ponto de partida (domínio → IP → outros domínios no mesmo IP…).
Entidade
Qualquer coisa investigável: domínio, IP, e-mail, username, CNPJ, pessoa…
Grafo de vínculos
O desenho de bolinhas (entidades) e linhas (relações) do dossiê.
RDAP
Sucessor moderno do WHOIS: dados oficiais de registro de domínios e blocos IP, em JSON.
DoH
DNS sobre HTTPS: consulta DNS criptografada via resolvedor (aqui, dns.google).
CT / crt.sh
Transparência de Certificados: registro público de todo certificado TLS emitido — ótimo para achar subdomínios.
InternetDB
Serviço gratuito da Shodan com portas/vulnerabilidades já indexadas de um IP — consultar não dispara scan.
SHA-256
Impressão digital matemática de um arquivo; mudou 1 bit, muda a impressão inteira.
Cadeia de custódia
Registro à prova de adulteração de quando/como cada evidência foi coletada.
Ledger hash-encadeado
Lista em que cada registro inclui o hash do anterior — como elos de uma corrente.
Orçamento
Os freios da investigação: profundidade, nº de entidades e nº de requisições.
Keyless
Fonte que não exige chave de API nem cadastro.
stdlib
A biblioteca padrão do Python — o GARIMPO usa só ela; nada de pip install.
Dígito verificador (DV)
Os dois últimos dígitos de CPF/CNPJ, calculados a partir dos outros. Se não batem, o número está errado — o GARIMPO checa isso sem internet.
Fronteira
Entidades descobertas que não foram consultadas (limite de profundidade, de entidades ou confiança baixa). Aparecem pontilhadas no grafo — são as próximas pistas.
ASN / BGP
Número do sistema autônomo (a "operadora" na internet) e o protocolo que anuncia quais blocos de IP ela controla.
STIX 2.1
Formato padrão (OASIS) para trocar inteligência de ameaças entre plataformas como MISP e OpenCTI.
GraphML
Formato XML de grafos, aberto pelo Gephi, yEd e Cytoscape.
MCP
Model Context Protocol: o padrão que deixa assistentes de IA (como o Claude) usarem ferramentas externas.
QSA
Quadro de Sócios e Administradores de uma empresa, público na Receita Federal.
publicIds (RDAP)
Campo do RDAP onde o registro.br publica o CNPJ do titular de domínios .br de empresas.
Profundidade
Quantos saltos de pivô separam uma entidade do seed: 0 é o seed, 1 é o que foi achado a partir dele.

14 · Seção técnica

Origem: engenharia reversa do OpenOSINT

O GARIMPO nasceu da dissecação do OpenOSINT/OpenOSINT (~22 mil linhas, 100 módulos): manteve o passivo-por-padrão, a tabela de ruído e o orçamento rígido; corrigiu 9 lacunas (Brasil ausente, dependência de LLM/chaves, extração por regex frágil, proveniência sem forense, instalação pesada, fontes keyless ignoradas, relatórios sem pt-BR…). O estudo completo, lacuna a lacuna com evidência no código, está em docs/ENGENHARIA-REVERSA-OPENOSINT.md.

Decisões de projeto

  • Sempre passivo — não existe flag de modo ativo; a classe de ferramenta que "toca o alvo" ficou fora por projeto, não por configuração.
  • CPF só offline — validação de dígitos verificadores e região fiscal; nenhuma consulta externa, por decisão ética documentada no código.
  • Extração estruturada — cada fonte devolve tuplas (tipo, valor, relação, confiança) a partir do JSON da API; o pivô nunca interpreta texto renderizado.
  • Confiança ≥ 0,6 para pivotar — herdada da calibração do OpenOSINT; abaixo disso a descoberta entra no grafo, mas não vira novo alvo.
  • Fato → evidência — cada fato guarda os números (#seq) das respostas brutas da chamada que o produziu; o dossiê e o painel linkam o arquivo e mostram o SHA-256.
  • Paralelo com cortesia — fontes de uma mesma camada rodam em paralelo, mas cada site recebe no máximo uma requisição a cada 0,35 s; a mesma URL nunca é pedida duas vezes na mesma investigação.
  • Fonte é plugin — uma função decorada com @fonte(nome, tipos, nível, destino, descrição); a tabela de ruído sai do registro, nunca de um texto mantido à mão.
  • Falha nunca derruba — timeout 15 s/requisição; erro vira registro de custódia com status_http: 0 e a investigação continua.
